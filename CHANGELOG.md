# Changelog

## 0.2.0 — 2026-10-26

- Expanded the tutorial server to 17 typed tools for task/list management, search, and a timezone-aware digest.
- Added strict input validation, explicit pagination, calendar-date filters, compact outputs, and bounded scans.
- Added PATCH updates, native moves, completion/reopening, title-checked deletion, and accurate clear/hide semantics.
- Added explicit write authorization and a read-only server mode.
- Separated browser sign-in from tool execution; added atomic owner-only token storage and refresh recovery.
- Added sanitized errors, bounded read retries, and no application-level mutation retries.
- Added behavior/protocol tests, package metadata, dependency snapshot, CI, documentation, and reference attribution.

## 0.1.0 — tutorial baseline

- Local Google OAuth and MCP tools for greeting, reading task lists, and reading tasks.
